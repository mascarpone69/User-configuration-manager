# User Configuration Manager

A Python program for managing user configuration settings such as theme, notifications, and volume.

## Features

* Add new user settings
* Update existing settings
* Delete settings
* View all current settings
* Automatically converts setting keys and values to lowercase
* Handles missing or duplicate settings with clear messages

## Technologies

* Python 3
* Dictionaries
* Tuples
* Functions
* Loops
* String methods

## Project

This project was created as part of the **freeCodeCamp Python certification** to practice working with dictionaries, functions, loops, and string manipulation.

## Example

```text
Current User Settings:
Theme: dark
Notifications: enabled
Volume: high
```
